Programming quick start

A simple example of sequence, selection and iteration — three fundamental programming constructs.

Example: Find the largest number

DECLARE a : INTEGER DECLARE b : INTEGER OUTPUT "Enter two numbers" INPUT a INPUT b IF a > b THEN OUTPUT a ELSE OUTPUT b ENDIF

This pseudocode inputs two numbers, compares them and outputs the larger one. If they are equal, the example outputs the second number, which is also the same value.

Three core constructs

  • Sequence: instructions execute in order.
  • Selection: a condition determines which path runs.
  • Iteration: instructions repeat while a loop condition or count requires it.
Exam tip: trace the algorithm line by line. Update variable values carefully and record each output in order.
