A simple first step

Programming, in plain language

A program is a set of instructions that tells a computer what to do.

Example: Find the larger number

INPUT numberA INPUT numberB IF numberA > numberB THEN OUTPUT numberA ELSE OUTPUT numberB ENDIF

This algorithm receives two numbers, compares them and outputs the larger number.

Three basic concepts

  • Sequence: instructions run one after another.
  • Selection: a condition decides what happens next.
  • Iteration: instructions repeat.
Remember: This is an introduction. Follow your teacher's instructions for the exact pseudocode style required by your course.
