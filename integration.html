Pure Mathematics

Integration

A deep Edexcel International A Level guide to integration, techniques, definite integrals, areas, curves and exam problem solving.

1. Integration: The Big Idea

Integration is fundamentally the reverse operation of differentiation. If differentiation tells us the rate at which a quantity changes, integration allows us to reconstruct a function from its rate of change.

If F′(x) = f(x), then ∫f(x) dx = F(x) + C

The function F is called an antiderivative of f. There are infinitely many antiderivatives because any constant disappears when differentiated.

d/dx (F(x) + C) = F′(x)

Why +C Exists

Suppose the derivative is 6x. Both 3x²+2 and 3x²−100 have derivative 6x. Therefore differentiation cannot tell us the original vertical position. The arbitrary constant restores that missing information.

∫6x dx = 3x² + C
Core idea: integration is not merely a collection of rules. Every integration answer should make sense as a function whose derivative returns the original integrand.

2. The Power Rule

For any real number n except −1:

∫xⁿ dx = xⁿ⁺¹/(n+1) + C

Why Does It Work?

Differentiate xⁿ⁺¹/(n+1):

d/dx [xⁿ⁺¹/(n+1)] = (n+1)xⁿ/(n+1) = xⁿ

This derivation explains the rule rather than requiring it to be memorised without understanding.

Worked Examples

∫x⁵ dx = x⁶/6 + C
∫7x⁴ dx = 7x⁵/5 + C
∫−3x² dx = −x³ + C
∫x⁻³ dx = −1/(2x²) + C
The power rule fails when n = −1 because division by n+1 would mean division by zero. That special case produces a logarithm.

3. Rewrite the Function Before Integrating

Many difficult-looking integrations become straightforward after algebraic rearrangement.

Roots

√x = x¹ᐟ²

Reciprocals

1/x³ = x⁻³

Example

∫(4√x + 3/x² − 5)dx

Rewrite:

∫(4x¹ᐟ² + 3x⁻² − 5)dx

Integrate term by term:

= 4(2/3)x³ᐟ² + 3(−x⁻¹) − 5x + C
= 8/3 x³ᐟ² − 3/x − 5x + C

Important Limitation

Not every quotient should simply be converted into powers. For example,

1/(x+2)

cannot be treated as x⁻¹+2⁻¹. The entire denominator matters.

4. Integration of 1/x and Logarithms

∫1/x dx = ln|x| + C

The absolute value is important because ln(x) is only defined for x>0, while 1/x exists for both positive and negative x.

Constant Multiple

∫k/x dx = k ln|x| + C

Linear Denominator

A particularly useful form is:

∫1/(ax+b) dx = (1/a)ln|ax+b| + C

Worked Example

∫ 5/(2x+3) dx
= 5/2 ln|2x+3| + C

Derivative Check

d/dx [5/2 ln|2x+3|] = 5/2 × 2/(2x+3) = 5/(2x+3)

5. Exponential Functions

Because the derivative of eˣ is eˣ itself:

∫eˣ dx = eˣ + C

For a linear exponent:

∫eᵃˣ dx = (1/a)eᵃˣ + C

Worked Example

∫3e⁵ˣ dx
= 3/5 e⁵ˣ + C

General Linear Exponent

∫e^(ax+b) dx = e^(ax+b)/a + C
The denominator comes from differentiating the inside: d/dx(ax+b)=a.

6. Basic Trigonometric Integrals

Know the derivative relationships in reverse.

∫cos x dx = sin x + C
∫sin x dx = −cos x + C
∫sec²x dx = tan x + C
∫cosec²x dx = −cot x + C
∫sec x tan x dx = sec x + C
∫cosec x cot x dx = −cosec x + C

With a Linear Angle

∫cos(3x)dx = 1/3 sin(3x) + C
∫sin(4x)dx = −1/4 cos(4x) + C
∫sec²(2x+1)dx = 1/2 tan(2x+1) + C

Power

∫xⁿdx = xⁿ⁺¹/(n+1)+C

Logarithm

∫1/x dx = ln|x|+C

Exponential

∫eˣdx = eˣ+C

Sine

∫sin x dx = −cos x+C

∫cos x dx = sin x+C

∫sec²x dx = tan x+C

Sec tan

8. Linearity of Integration

Integration is linear. Constants can be taken outside, and sums can be integrated term by term.

∫[af(x)+bg(x)]dx = a∫f(x)dx+b∫g(x)dx

Example

∫(4x³−7x+9)dx
= x⁴ − 7x²/2 + 9x + C

Important Concept

You may split addition and subtraction:

∫(f+g)dx = ∫f dx + ∫g dx

but multiplication generally cannot be split:

∫f(x)g(x)dx is NOT generally equal to (∫f(x)dx)(∫g(x)dx).

9. Definite Integration

A definite integral has limits and therefore produces a number rather than a family of functions.

∫ₐᵇf(x)dx = [F(x)]ₐᵇ = F(b)−F(a)

Example

∫₁⁴(2x+3)dx
F(x)=x²+3x
F(4)−F(1) =28−4 =24

Why +C Is Not Needed

If we wrote F(x)+C at both limits:

[F(b)+C]−[F(a)+C] =F(b)−F(a)

The constants cancel. Therefore +C is unnecessary in a definite integral.

10. Properties of Definite Integrals

∫ₐᵇf(x)dx = −∫ᵇₐf(x)dx
∫ₐᵃf(x)dx = 0
∫ₐᵇf(x)dx + ∫ᵇᶜf(x)dx = ∫ₐᶜf(x)dx

Constant Multiple

∫ₐᵇkf(x)dx = k∫ₐᵇf(x)dx

Symmetry

For an odd function:

∫₋ₐᵃf(x)dx = 0

For an even function:

∫₋ₐᵃf(x)dx = 2∫₀ᵃf(x)dx

Example

∫₋²² x³ dx = 0

because x³ is odd.

11. Integration by Substitution

Substitution is the reverse of the chain rule. It is useful when part of the integrand resembles the derivative of another part.

u = g(x)
du = g′(x)dx

The goal is to rewrite the entire integral in terms of u.

Worked Example

∫2x(x²+1)⁵dx

Let:

u=x²+1
du=2x dx

Therefore:

∫u⁵du = u⁶/6+C
= (x²+1)⁶/6+C

Recognition Pattern

∫g′(x)[g(x)]ⁿdx = [g(x)]ⁿ⁺¹/(n+1)+C

12. Advanced Substitution Recognition

Example A

∫ x/(x²+4) dx

Let u=x²+4, so du=2x dx.

=1/2∫1/u du
=1/2 ln|x²+4|+C

Example B

∫e^(3x−2)dx
u=3x−2
du=3dx
=1/3e^(3x−2)+C

Example C

∫cos(5x+1)dx
=1/5 sin(5x+1)+C
When using substitution, do not leave a mixture of x and u in the final integral. Convert everything consistently.

13. Substitution in Definite Integrals

There are two clean methods. Either convert back to x before applying the limits, or transform the limits into u-values.

Example

∫₀² 2x(x²+1)³dx

Let u=x²+1.

du=2x dx

Transform the limits:

x=0 → u=1
x=2 → u=5
∫₁⁵u³du
=[u⁴/4]₁⁵
=(625−1)/4 =156
Once the variable becomes u, use u-limits. Do not substitute the original x-limits into a u-expression.

14. Integration by Parts

Integration by parts is the reverse of the product rule.

∫u dv = uv − ∫v du

It is especially useful for products such as:

  • x eˣ
  • x sin x
  • x cos x
  • x ln x
  • polynomial × exponential
  • polynomial × trigonometric function

Choosing u

A useful practical guideline is to choose as u the factor that becomes simpler when differentiated.

Worked Example

∫x eˣ dx
u=x
dv=eˣdx
du=dx
v=eˣ
∫x eˣdx = xeˣ−∫eˣdx
=eˣ(x−1)+C

Check

d/dx[eˣ(x−1)] =eˣ(x−1)+eˣ =xeˣ

15. Integration by Parts: Deeper Examples

Example A — x sin x

∫x sin x dx
u=x
dv=sin x dx
du=dx
v=−cos x
=−x cos x + ∫cos x dx
=−x cos x + sin x + C

Example B — ln x

There is no visible product, but write ln x as ln x × 1.

∫ln x dx
u=ln x
dv=dx
du=1/x dx
v=x
=x ln x−∫1 dx
=x ln x−x+C

Example C — x²eˣ

Integration by parts must be repeated.

∫x²eˣdx = x²eˣ−∫2xeˣdx

Using parts again:

∫xeˣdx=eˣ(x−1)
∫x²eˣdx = eˣ(x²−2x+2)+C

16. Partial Fractions Before Integration

Rational functions may sometimes be decomposed into simpler fractions. This is particularly useful when the denominator factors into linear factors.

Basic Form

1/[(x+a)(x+b)] = A/(x+a)+B/(x+b)

Worked Example

∫ 1/[(x+1)(x+2)] dx

Write:

1/[(x+1)(x+2)] = A/(x+1)+B/(x+2)

Therefore:

1=A(x+2)+B(x+1)

Put x=−1:

1=A

Put x=−2:

1=−B
A=1,\qquad B=−1

So:

∫[1/(x+1)−1/(x+2)]dx
=ln|x+1|−ln|x+2|+C

17. Partial Fractions with Repeated Factors

If a denominator contains a repeated linear factor, include every required power.

1/[x(x+1)²] = A/x+B/(x+1)+C/(x+1)²

Omitting the repeated-power term makes the decomposition incomplete.

Integration Result

∫C/(x+1)²dx = −C/(x+1)
Always factor the denominator completely before deciding the partial fraction form.

18. Quadratic Denominators and Completing the Square

Some quadratic expressions are better handled by completing the square.

x²+6x+13=(x+3)²+4

This can reveal standard forms involving logarithms or inverse tangent depending on the numerator and structure.

Example

∫ dx/[(x+3)²+4]

Use:

∫du/(u²+a²) = 1/a tan⁻¹(u/a)+C
=1/2 tan⁻¹((x+3)/2)+C

19. Area Under a Curve

If y=f(x) is non-negative on [a,b], then the geometric area between the curve and x-axis is:

Area=∫ₐᵇf(x)dx

Example

y=4−x²

From x=0 to x=2:

Area=∫₀²(4−x²)dx
=[4x−x³/3]₀²
=8−8/3 =16/3

20. Signed Area vs Geometric Area

A definite integral measures signed area. Region above the x-axis contributes positively, while region below contributes negatively.

∫ₐᵇf(x)dx

is therefore not automatically the total geometric area.

Example

y=x−2

From x=0 to x=4, the curve crosses the x-axis at x=2.

Therefore split the region:

Area=−∫₀²(x−2)dx + ∫₂⁴(x−2)dx
Area=4
If the question says "total area", "area enclosed", or "geometrical area", you must account for regions below the axis rather than blindly accepting a negative integral.

21. Area Between Two Curves

When integrating with respect to x:

Area=∫ₐᵇ(upper−lower)dx

Example

y=x
y=x²

Between x=0 and x=1, x lies above x².

Area=∫₀¹(x−x²)dx
=[x²/2−x³/3]₀¹
=1/6

Finding the Limits

If the limits are not given, solve the intersection equation:

f(x)=g(x)

Those x-values become the integration boundaries.

22. Area Problems Where the Curves Intersect

Worked Example

Find the area enclosed by y=2x and y=x².

First find intersections:

2x=x²
x(x−2)=0
x=0,2

Between 0 and 2, 2x is above x².

Area=∫₀²(2x−x²)dx
=[x²−x³/3]₀²
=4−8/3 =4/3
For every area-between-curves question, consciously identify: boundaries → upper curve → lower curve → integral → exact value.

23. Parameter and Unknown-Area Problems

Integration questions can ask you to determine an unknown constant from an area condition.

Example Structure

Suppose:

y=k−x²

The area between the curve and x-axis from x=−2 to x=2 is 16. Find k.

∫₋²²(k−x²)dx=16

Using symmetry:

2∫₀²(k−x²)dx=16
2[ kx−x³/3 ]₀²=16
4k−16/3=16
4k=64/3
k=16/3

24. Volumes of Revolution

When a region is rotated around the x-axis, the volume can be found using:

V=π∫ₐᵇy²dx

Example

Rotate y=x from x=0 to x=2 about the x-axis.

V=π∫₀²x²dx
=π[x³/3]₀²
V=8π/3
The radius is y, so the cross-sectional area is πy², not πy.

25. Multi-Step Integration Challenge

The curve is y=x(4−x), and the x-axis forms a bounded region with the curve.

Step 1 — Intersections

x(4−x)=0
x=0,4

Step 2 — Area

A=∫₀⁴(4x−x²)dx
=[2x²−x³/3]₀⁴
=32−64/3 =32/3

26. Integration in Differential Equations

Integration is frequently used to recover a quantity from its derivative.

dv/dt = f(t)

Integrating:

v=∫f(t)dt

A condition such as v=12 when t=0 can then determine C.

Example

dv/dt=6t+4
v=3t²+4t+C

If v=7 at t=0:

7=C
v=3t²+4t+7

27. Why Definite Integration Represents Accumulation

Imagine splitting an interval into many tiny strips of width Δx. Each strip has approximate area:

f(x)Δx

Adding all strips gives an approximation to the total accumulated quantity. As the strips become infinitely thin, the sum becomes an integral.

∫ₐᵇf(x)dx

This explains why integration appears in area, displacement, accumulated growth, work, volume and many other applications.

28. Differentiating an Integral-Defined Function

If:

F(x)=∫ₐˣf(t)dt

then:

F′(x)=f(x)

The variable inside the integral can be called t, u, or another dummy variable. It is the upper limit x that changes.

Example

F(x)=∫₂ˣ(3t²+1)dt
F′(x)=3x²+1

29. Variable Upper Limits

If the upper limit itself is a function of x:

F(x)=∫ₐ^{g(x)}f(t)dt

then the chain rule gives:

F′(x)=f(g(x))g′(x)

Example

F(x)=∫₁^{x²}sin(t)dt
F′(x)=sin(x²)·2x
F′(x)=2x sin(x²)

30. Choosing the Correct Technique

A major part of integration is recognising the structure before doing algebra.

Simple powers

Use power rule.

1/x

Use ln|x|.

Function × derivative of function

Try substitution.

Product such as xeˣ

Try integration by parts.

Rational expression with factorised denominator

Try partial fractions.

Quadratic + constant square

Complete the square / inverse tangent form.

31. Hard Worked Examples

Example 1

∫ x/(x²+9) dx
u=x²+9
du=2x dx
=1/2∫du/u
=1/2ln(x²+9)+C

Example 2

∫x²ln x dx

Use integration by parts:

u=ln x
dv=x²dx
du=1/x dx
v=x³/3
=x³/3 ln x − 1/3∫x²dx
=x³/3 ln x−x³/9+C

Example 3

∫(2x+3)/(x²+3x+5) dx

Notice that the numerator is exactly the derivative of the denominator.

u=x²+3x+5
du=(2x+3)dx
=ln(x²+3x+5)+C

32. Parameter Questions

Challenge A

The curve has gradient:

dy/dx=3x²−4x+a

and passes through (1,5). If its y-intercept is 2, find a.

Show solution
y=x³−2x²+ax+C

Since y(0)=2:

C=2

Using (1,5):

5=1−2+a+2
a=4

Challenge B

Find k if:

∫₀¹(kx²+2x)dx=3
Show solution
k/3+1=3
k=6

33. Common Integration Traps

Trap 1 — Forgetting +C

Indefinite integral → include +C.

Trap 2 — Wrong power denominator

∫x⁵dx=x⁶/6+C

Not x⁶/5.

Trap 3 — Treating 1/x as x⁻¹ under the ordinary rule

∫x⁻¹dx=ln|x|+C

Trap 4 — Forgetting the inner derivative

∫cos(5x)dx=1/5sin(5x)+C

Trap 5 — Upper minus lower

[F(x)]ₐᵇ=F(b)−F(a)

Trap 6 — Signed area

An integral can be negative even though geometric area cannot.

Trap 7 — Wrong curve in area questions

Always determine which function is above the other over the interval.

Trap 8 — Mixing variables during substitution

Once you switch to u, complete the integral in u.

Trap 9 — Incorrect by-parts signs

∫u dv=uv−∫v du

Trap 10 — Incomplete partial fractions

Repeated factors require repeated-power terms.

34. Edexcel Exam Strategy

  1. Rewrite the integrand into a recognisable form.
  2. Look for a standard integral.
  3. Check whether substitution is possible.
  4. If there is a product, consider integration by parts.
  5. If there is a factorised rational expression, consider partial fractions.
  6. For definite integrals, write the limits clearly.
  7. For areas, find intersections before integrating if necessary.
  8. Keep exact values until the final step.
  9. Check signs carefully.
  10. Differentiate an indefinite answer whenever practical.
High-level habit: Before writing any algebra, spend a few seconds asking "What structure am I looking at?" Technique recognition often saves more time than faster calculation.
