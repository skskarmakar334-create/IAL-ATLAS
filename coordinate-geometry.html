Coordinate Geometry.

A deep, structured guide to coordinates, distance, midpoint, ratio, gradients, straight lines, perpendicularity, intersections, coordinate proofs, circles and exam problem solving.

1. The Coordinate Plane

Coordinate geometry connects algebra and geometry by representing points, lines and shapes numerically. Instead of describing a point only by its position in a diagram, we can describe it exactly using ordered pairs.

Cartesian Coordinates

A point is written as:

(x, y)

The first value is the x-coordinate and the second value is the y-coordinate.

  • x measures horizontal displacement.
  • y measures vertical displacement.
  • Positive x-values lie to the right of the y-axis.
  • Negative x-values lie to the left of the y-axis.
  • Positive y-values lie above the x-axis.
  • Negative y-values lie below the x-axis.

The Four Quadrants

I: (+,+)    II: (-,+)    III: (-,-)    IV: (+,-)

The Origin

The intersection of the coordinate axes is called the origin:

O = (0,0)
Example:

The point A has coordinates (-4, 7). Therefore A lies in Quadrant II because x is negative and y is positive.

2. Distance Between Two Points

Suppose two points are:

A(x₁,y₁),   B(x₂,y₂)

The horizontal change is:

Δx = x₂ − x₁

The vertical change is:

Δy = y₂ − y₁

These two changes form the perpendicular sides of a right-angled triangle. Pythagoras' theorem therefore gives the distance.

AB = √[(x₂ − x₁)² + (y₂ − y₁)²]

Why the Formula Works

If the horizontal difference is 3 and the vertical difference is 4, then the points form a 3-4-5 triangle:

AB² = 3² + 4² = 25
AB = 5

Worked Example

Find the distance between A(-2,3) and B(4,11).

AB = √[(4+2)² + (11−3)²]
= √(6² + 8²)
= √100
AB = 10

Distance Squared

Sometimes it is unnecessary to calculate the square root. For example, to compare two distances, compare their squares instead.

AB² = (x₂−x₁)² + (y₂−y₁)²
This is particularly useful in coordinate proofs involving equal lengths because it avoids unnecessary square roots.

3. Midpoint of a Line Segment

The midpoint is the point exactly halfway between two endpoints.

For:

A(x₁,y₁), B(x₂,y₂)

the midpoint is:

M = ((x₁+x₂)/2 , (y₁+y₂)/2)

Notice that the x-coordinates are averaged separately from the y-coordinates.

Example:

Find the midpoint of A(-3,8) and B(7,2).

M = ((−3+7)/2 , (8+2)/2)
M = (2,5)

Finding an Unknown Endpoint

The midpoint formula can also be rearranged to find an unknown endpoint.

Suppose A(x₁,y₁), B(x₂,y₂) and midpoint M(xₘ,yₘ).

xₘ = (x₁+x₂)/2
yₘ = (y₁+y₂)/2

Therefore:

x₂ = 2xₘ − x₁
y₂ = 2yₘ − y₁
Example:

A point A is (3,7) and the midpoint of AB is (8,4). Find B.

x_B = 2(8)−3 = 13
y_B = 2(4)−7 = 1
B = (13,1)

4. Dividing a Line Segment in a Given Ratio

Coordinate geometry can be used to locate a point dividing a line segment internally in a specified ratio.

If P divides AB in the ratio:

AP : PB = m : n

where:

A(x₁,y₁), B(x₂,y₂)

then:

P = ((nx₁ + mx₂)/(m+n), (ny₁ + my₂)/(m+n))
Example:

P divides A(2,3) and B(12,8) in the ratio 2:3.

x_P = [3(2)+2(12)]/5 = 30/5 = 6
y_P = [3(3)+2(8)]/5 = 25/5 = 5
P = (6,5)
Be careful with the ratio formula. The coefficient beside A is the part opposite A, while the coefficient beside B is the part opposite B.

5. Gradient of a Straight Line

The gradient measures the rate at which y changes as x changes.

m = (y₂−y₁)/(x₂−x₁)

This can also be understood as:

gradient = vertical change / horizontal change

Positive Gradient

A line with positive gradient rises from left to right.

Negative Gradient

A line with negative gradient falls from left to right.

Zero Gradient

A horizontal line has:

m = 0

Undefined Gradient

A vertical line has x₂−x₁ = 0, so division by zero is impossible. Therefore a vertical line has no finite gradient.

Example:

Find the gradient through A(-2,5) and B(4,-7).

m = (−7−5)/(4−(−2))
= −12/6
m = −2

6. Equation of a Straight Line

Slope-Intercept Form

y = mx + c

where m is the gradient and c is the y-intercept.

Point-Gradient Method

If the gradient is m and the line passes through (x₁,y₁):

y − y₁ = m(x − x₁)
Example:

Find the equation of the line with gradient -3 passing through (4,7).

y − 7 = −3(x−4)
y − 7 = −3x + 12
y = −3x + 19

Finding the Equation from Two Points

  1. Calculate the gradient.
  2. Use either point in y = mx + c.
  3. Find c.
  4. Write the final equation.
Example:

Find the equation through (1,4) and (5,12).

m = (12−4)/(5−1) = 2
y = 2x+c
4 = 2(1)+c
c = 2
y = 2x+2

7. Important Forms of a Straight Line

Gradient-Intercept Form

y = mx+c

Point-Gradient Form

y−y₁ = m(x−x₁)

General Form

ax + by + c = 0

The general form can be rearranged into y = mx+c when necessary.

Consider:

3x + 2y − 8 = 0

Rearrange:

2y = −3x+8
y = −3/2 x + 4

Therefore the gradient is:

−3/2

Horizontal Line

y = k

Vertical Line

x = k

8. Parallel Lines

Two non-identical straight lines are parallel if they have the same gradient.

m₁ = m₂

Determine whether:

y = 4x−7

and:

2y = 8x+5

are parallel.

The second equation becomes:

y = 4x + 5/2

Both gradients are 4, so the lines are parallel.

Finding a Parallel Line

If a line has gradient m, every parallel line has the same gradient. The constant c changes according to the point through which the new line passes.

9. Perpendicular Lines

For two non-vertical perpendicular lines:

m₁m₂ = −1

Therefore the gradient of a perpendicular line is the negative reciprocal.

m₂ = −1/m₁

A line has gradient 5.

m₂ = −1/5

Therefore a perpendicular line has gradient -1/5.

Do not confuse the reciprocal with the negative reciprocal. The perpendicular gradient to 3 is -1/3, not 1/3.

10. Proving Points Are Collinear

Points are collinear if they all lie on the same straight line.

Method 1 — Compare Gradients

For A, B and C, calculate:

gradient AB
and:
gradient BC

If they are equal, the three points are collinear.

A(1,2), B(3,6), C(5,10)

m_AB = (6−2)/(3−1)=2
m_BC = (10−6)/(5−3)=2

Therefore the points are collinear.

Method 2 — Find the Equation

Find the equation through two points and substitute the third point. If it satisfies the equation, the points are collinear.

11. Intersections of Lines

At the intersection of two lines, the coordinates of the point satisfy both equations simultaneously.

Therefore if:

y = 2x+3
y = −x+9

set them equal:

2x+3 = −x+9
3x = 6
x = 2

Substitute x = 2:

y = 2(2)+3 = 7
Intersection = (2,7)

12. Intersections of a Line and a Curve

If a line and curve intersect, the coordinates must satisfy both equations.

For example:

y = x+6
y = x²

Set them equal:

x² = x+6
x²−x−6 = 0
(x−3)(x+2)=0
x = 3 or x = −2

Then substitute each x-value into either original equation to obtain the corresponding y-coordinate.

If a question asks for coordinates of intersection, giving only the x-values is incomplete.

13. Intersections and Quadratic Discriminants

When a line is substituted into a quadratic curve, the resulting equation is often quadratic.

For:

ax²+bx+c=0

the discriminant is:

Δ = b²−4ac
  • Δ > 0 → two distinct real intersections.
  • Δ = 0 → one repeated intersection, usually tangency.
  • Δ < 0 → no real intersections.

Suppose a line intersects a curve and substitution produces:

x²−6x+9=0

Then:

Δ = (−6)²−4(1)(9)=0

Therefore there is one repeated root and hence one point of contact.

14. Coordinate Geometry Proofs

Coordinate geometry can prove geometric properties algebraically. Instead of relying only on a diagram, calculate quantities that establish the required property.

Proving a Shape Is Isosceles

Show that two sides have equal lengths.

AB² = AC²

Proving a Shape Is Equilateral

Show all three side lengths are equal.

AB² = BC² = CA²

Proving a Shape Is a Parallelogram

Possible methods include:

  • Show opposite sides have equal gradients and lengths.
  • Show opposite sides have equal gradients.
  • Show the diagonals have the same midpoint.

Proving a Rectangle

A rectangle can be established by showing opposite sides are parallel and one pair of adjacent sides is perpendicular.

Proving a Right Angle

m₁m₂ = −1

15. Coordinate Geometry of Circles

A circle with centre (a,b) and radius r has equation:

(x−a)² + (y−b)² = r²

Recognising the Centre and Radius

Consider:

(x−3)²+(y+4)²=25

Compare with:

(x−a)²+(y−b)²=r²

Therefore:

centre = (3,−4)
radius = 5

Circle Through the Origin

If the circle passes through (0,0), substitute x=0 and y=0 into the equation to obtain a relationship between the constants.

Expanded Circle Equation

Expanding:

(x−a)²+(y−b)²=r²

gives:

x²+y²−2ax−2by+a²+b²−r²=0

This can be compared with a general circle equation to determine its centre and radius.

16. Tangents to Circles

A tangent touches a circle at exactly one point. The radius drawn to the point of contact is perpendicular to the tangent.

gradient(radius) × gradient(tangent) = −1

Suppose the centre of a circle is C(2,3) and the point of contact is P(6,5).

First find the gradient CP:

m_CP = (5−3)/(6−2)=1/2

Therefore the tangent gradient is:

m_tangent = −2

The tangent passes through P(6,5):

y−5 = −2(x−6)
y = −2x+17

17. Chords and Their Midpoints

A chord is a line segment joining two points on a circle.

A key coordinate-geometry fact is that the perpendicular from the centre of a circle to a chord bisects the chord.

Therefore, if M is the midpoint of chord AB, then:

AM = MB

and:

CM ⟂ AB

This creates a useful combination of midpoint and perpendicular-gradient methods.

18. Circle-Line Relationships

To determine whether a line intersects a circle, substitute the line equation into the circle equation.

This produces an equation in x.

  • Two real solutions → line intersects circle twice.
  • One repeated real solution → line is tangent.
  • No real solutions → line does not meet the circle.

The same conclusion can be reached geometrically by comparing the distance from the centre to the line with the radius, when the relevant distance formula is available.

19. A Reliable Coordinate Geometry Method

When Given Two Points

  1. Write down the coordinates clearly.
  2. Calculate Δx and Δy.
  3. Decide whether you need distance, midpoint or gradient.
  4. Keep exact values where appropriate.
  5. Check signs carefully.

When Finding a Line

  1. Find the gradient.
  2. Choose the most convenient line equation form.
  3. Use the given point.
  4. Simplify completely.
  5. Check the point satisfies the final equation.

When Finding an Intersection

  1. Make the equations represent the same variable.
  2. Equate them.
  3. Solve the resulting equation.
  4. Find every valid x-value.
  5. Substitute to obtain y-values.
  6. State the coordinates clearly.

20. Common Mistakes

1. Reversing x and y

Always remember:

(x,y)

2. Inconsistent subtraction

In the gradient formula, if you use y₂−y₁, use x₂−x₁.

3. Forgetting negative signs

Negative coordinates frequently appear in coordinate geometry. Use brackets when substituting them.

−3 − (−7)

is not the same as:

−3 − 7

4. Confusing perpendicular gradients

m₂ = −1/m₁

5. Giving only x-values

If the question asks for coordinates, calculate y as well.

6. Decimalising too early

Exact fractions and surds are usually safer during working.

7. Not checking the answer

Substitute your result back into the original equation whenever possible.

21. Deeper Problem-Solving Techniques

Technique A — Work Backwards

If the final point or gradient is known, work backwards through the equations to determine an unknown coordinate.

Technique B — Use Distance Squared

When proving two distances equal, use:

distance² = Δx² + Δy²

This removes unnecessary square roots.

Technique C — Use the Midpoint of Diagonals

For a parallelogram, the diagonals bisect each other. Therefore their midpoints are equal.

Technique D — Convert General Equations

If a line is given in general form, rearrange it into y=mx+c when you need its gradient.

Technique E — Look for Structure

If coordinates contain symmetric values such as:

(a,b), (−a,b), (a,−b), (−a,−b)

look for symmetry around the axes or origin before doing lengthy calculations.
